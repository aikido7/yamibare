# 🔦 ヤミバレ — 届いたら、貼るだけ。

若者を特殊詐欺の「被害者」にも、闇バイトの「実行役」にもさせないためのチェッカー。
怪しいDM・バイト募集・儲け話を貼るだけで、危険サインとオープンデータを根拠に「ヤバさ」を照らします。

**▶ 公開版: https://yamibare.pages.dev**

都知事杯オープンデータ・ハッカソン2026 応募プロジェクト(チーム ヤミバレ)

## なぜ作ったか

「詐欺は高齢者の問題」は、もう古い —

- ニセ警察詐欺の被害件数は **30代が最多(2,239件)、20代が2位(1,718件)**(警察庁・令和7年)
- 警察が約1年で保護した闇バイト応募者544人のうち **8割超が10〜30代**(警察庁・2026年1月発表)
- それでも既存の啓発は高齢者向け・一方向のままで、「自分は騙されない」と思っている若者には届かない

## 何ができるか

1. **貼るだけ判定** — LINE風チャットに文面を貼ると、ヤバ度0〜99と「引っかかった言葉」を根拠つきで表示(8カテゴリ: 闇バイト/ニセ警察/SNS投資/ロマンス/還付金/フィッシング/サポート/チケット)
2. **闇バイト専用警告** — 「もう応募してしまっても、今なら戻れる」と出口を示し、#9110へワンタップ発信
3. **わがまちデータ** — 警視庁オープンデータ(59区市町村・町丁TOP3)で「自分の街」の実数を表示
4. **シェアカード** — 判定結果をPNG化して友達へ。「守られる側」から「守る側」に

## 設計原則

- **端末内判定・外部送信ゼロ** — 貼った文面はどこにも送らない。誰にも知られず確認できる
- **「安全」と断定しない** — 低スコアでも必ず注意喚起と相談導線を表示
- **単一HTML・依存ゼロ** — URLひとつでどのスマホでも動く(Cloudflare Pages配信)

## デモモード(検証・撮影用)

URLパラメータで判定画面を即再現できます:

- `?demo=yamibaito` / `police` / `invest` / `romance` / `sms` — 各サンプルの判定結果
- `?demo=yamibaito&focus=alert` — 闇バイト専用警告へフォーカス
- `?demo=machi&area=新宿区` — わがまちデータ表示
